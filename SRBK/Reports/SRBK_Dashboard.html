                DCF Valuation

                📊 Model Approach: Residual Income on Tangible Book (Not a Standard FCF DCF)

                SR Bancorp is a bank holding company — a conventional unlevered free-cash-flow DCF is not meaningful for a depository institution because loan/deposit flows swamp any FCF proxy and regulatory capital rules constrain distributions. Instead this model discounts residual income — (ROE − Cost of Equity) × beginning tangible book value — back to the present, then adds the present value of a terminal exit value based on an assumed exit Price/Tangible-Book multiple in place of a Gordon-growth perpetuity.

                • Sanity check passed: implied P/TBV of the base-case intrinsic value is 0.75x (below the 0.89x historical high since the Oct-2023 IPO) and implied P/E of 23.7x is below 2x the historical average — the model is not extrapolating unsustainable peak performance.
                • Sub-book intrinsic values in Base/Bear are intentional, not a bug: SRBK's ROE (~2–5% across scenarios) sits well below its ~9.5–10.5% cost of equity, so absent a sale, continuing as a going concern mechanically destroys a sliver of value each year even as buybacks and dividends return capital.
                • Upside case = M&A takeout: the standard 3-year post-conversion anti-takeover moratorium expires September 2026. The Bull scenario models a 3-year exit at 1.25x tangible book, consistent with historical NJ thrift-conversion takeout multiples once that regulatory restriction lifts.
